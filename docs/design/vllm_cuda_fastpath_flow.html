Quick Notes

paged attention The Python wrappers in vllm/_custom_ops.py call into compiled kernels registered by vllm/_C.abi3.so.

backend choice CUDA uses backend priorities in vllm/platforms/cuda.py and the registry in vllm/v1/attention/backends/registry.py.

cudagraph When enabled, attention backends expose capture-aware paths to reduce launch overhead.
